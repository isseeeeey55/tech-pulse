# Claude Code v2.1.147 & v2.1.146 リリース情報

## はじめに

2026年5月22日、Claude Code の v2.1.147 と v2.1.146 がリリースされました。今回のアップデートでは、マルチエージェント オーケストレーションを実現する Workflow ツールの追加、コードレビュー機能の強化と改名、セッション管理の改善が行われました。また、Windows PowerShell の不具合修正、MCP リソースのページネーション問題解決、セキュリティ強化など、安定性と信頼性の向上を図る多数の修正が含まれています。

## 注目アップデート深掘り

### Workflow ツールによるマルチエージェント オーケストレーション

v2.1.147 では、マルチエージェント オーケストレーションを実現する Workflow ツールが新たに追加されました。これにより、複数のエージェントを連携させた複雑なタスク処理が可能になります。

> **Note:** Workflow ツールは、複数のエージェントを組み合わせて処理フローを構築する Claude Code の機能です。

この機能は、複雑な開発タスクを段階的に分割し、各エージェントに適切な役割を割り当てることで、より効率的な自動化を実現します。REPL および Workflow サンドボックスのセキュリティも同時に強化されており、安全な実行環境が提供されます。

### コードレビュー機能の拡充と改名

v2.1.147 では `/simplify` コマンドが `/code-review` に改名され、機能も大幅に強化されました。新たに努力レベル（effort level）の指定が可能になり、レビューの深度を調整できるようになりました。また、GitHub PR へのコメント投稿機能も追加され、レビュー結果を直接プルリクエストにフィードバックできるようになっています。

v2.1.146 でもコードレビューコマンドの強化が行われており、2バージョンにわたって継続的に改善が進められています。これにより、コードレビュープロセスがより実践的なワークフローに統合されやすくなりました。

## 実用的な活用ポイント

今回のリリースでは、セッション管理の改善として、ピン留めしたセッションがアイドル時にも保持されるようになりました。長時間にわたるタスクや、定期的に参照したいセッションを維持しやすくなります。

大規模ファイル編集時のパフォーマンスが改善されたことで、大きなコードベースでの作業がより快適になります。また、ストリーミング時の UI 改善により、リアルタイムでの応答表示がスムーズになりました。

Windows ユーザーにとっては、PowerShell の不具合修正により、より安定した動作が期待できます。MCP リソースのページネーション問題も解決され、大量のリソースを扱う際の信頼性が向上しています。

オートアップデーターの信頼性向上により、今後のバージョンアップがより確実に行われるようになります。

## まとめ

v2.1.147 と v2.1.146 は、新機能の追加と既存機能の改善をバランス良く含んだアップデートとなりました。Workflow ツールの追加により、マルチエージェント連携という新しい可能性が開かれ、コードレビュー機能の強化により実際の開発ワークフローへの統合が進んでいます。

また、Windows 環境での安定性向上、MCP の信頼性改善、パフォーマンス最適化など、日常的な利用における品質向上にも注力されています。セキュリティ強化とオートアップデーターの改善により、今後も安全かつ確実にアップデートを受け取れる基盤が整えられました。
