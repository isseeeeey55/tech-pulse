# Claude Code v2.1.159 リリース情報

## はじめに

2026年6月1日、Claude Code v2.1.159 がリリースされました。本バージョンは内部インフラストラクチャの改善のみで、公式チェンジログにも「Internal infrastructure improvements (no user-facing changes)」と記載されているとおり、ユーザー向けの変更は含まれていません。新機能やバグ修正の追加はなく、内部基盤のメンテナンスを目的としたリリースです。

## 全変更点一覧

| カテゴリ | 内容 | 概要 |
|---------|------|------|
| Improvement | 内部インフラストラクチャの改善 | ユーザー向けの変更を伴わない内部基盤の改善（公式チェンジログの記載は1行のみ） |

## まとめ

v2.1.159 は、ユーザー向けの変更を含まない内部インフラストラクチャのメンテナンスリリースです。公式チェンジログの記載も「Internal infrastructure improvements (no user-facing changes)」の1行のみで、新機能・バグ修正の発表はありません。日常の利用に影響する変更はないため、アップデートは任意のタイミングで差し支えありません。
