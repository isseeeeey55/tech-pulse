# Claude Code v2.1.172 リリース情報

## はじめに

2026年6月11日、Claude Code v2.1.172 がリリースされました。本バージョンでは、Sub-agents の多段階化（最大5レベル）、AWS Bedrock のリージョン設定自動検出の改善、プラグインマーケットプレイスへの検索機能追加が実施されました。また、1M コンテキスト使用時のセッション永続化問題、背景エージェントの設定ファイル隔離、モデル選択UI の不整合といった複数の不具合が修正され、エージェント機能の安定性と使いやすさが向上しています。

## 注目アップデート深掘り

### Sub-agents の多段階化（最大5レベル）

今回のリリースで Sub-agents が最大5レベルまで多段階化されました。これにより、依存関係のある複雑なタスクを段階的に処理できるようになります。リリースノートによれば、Terraform/CloudFormation テンプレート生成時に「VPC → セキュリティグループ → アプリケーション層」といった依存関係を正確に処理できるとされています。大規模インフラ設計において、各レイヤーを順序立てて検証・修正するワークフローの効率化が期待されます。

### AWS Bedrock リージョン設定の自動検出改善

AWS Bedrock のリージョン設定自動検出が改善され、`~/.aws/config` ベースの環境自動適用が可能になりました。これにより、マルチリージョン運用時の設定ミスを削減できます。リリースノートでは、AWS 運用環境での即座な連携強化が強調されており、複数リージョンにまたがるインフラ管理の手間が軽減されることが示されています。

## 実用的な活用ポイント

今回のリリースで修正された1M コンテキストのセッション永続化問題により、大量のログ解析や複数ファイルの同時検査が安定して実行できるようになりました。また、背景エージェントの設定ファイル隔離（.mcp.json）により、複数プロジェクトを並行処理する際に権限・信頼設定の誤適用を防止できます。リリースノートでは、CloudFormation スタック検証やポリシー監査の自動化を安心して運用できると述べられています。さらに、モデル選択UI の修正により、Opus 1M などのハイスペックモデルを意図通りに活用でき、複雑な Lambda 関数やカスタム CloudWatch メトリクス生成を支援します。

## まとめ

Claude Code v2.1.172 は、Sub-agents の多段階化や AWS Bedrock 連携の改善といった新機能に加え、1M コンテキストのセッション永続化や設定ファイル隔離など複数の不具合修正を含むリリースです。リリースノートで言及されている通り、Terraform/CloudFormation テンプレート生成の依存関係処理、マルチリージョン運用時の設定ミス削減、大量ログ解析の安定性向上、複数プロジェクト並行処理時の設定誤適用防止など、エージェント機能の安定性と使いやすさが向上しています。プラグインマーケットプレイスへの検索機能追加も、エコシステムの利便性向上に寄与するでしょう。
