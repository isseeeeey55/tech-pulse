# Claude Code v2.1.170 リリース情報

## はじめに

2026年6月10日、Claude Code **v2.1.170** がリリースされました。本バージョンでは、新しいMythos級モデル「Claude Fable 5」が一般利用可能になり、従来比で大幅に能力が向上しました。加えて、VS Code統合ターミナルからの起動時にセッションが保存されないバグの修正が行われています。

## 注目アップデート深掘り

### Claude Fable 5（Mythos級モデル）の一般提供開始

今回のリリースで、Claude Fable 5がすべてのユーザーに利用可能となりました。Fable 5はMythos級に分類される新しいモデルで、従来モデルと比較して大幅に能力が向上しています。

リリースノートでは「より複雑なコーディングタスクに対応」できるようになったと明記されており、これまで対応が難しかった高度なプログラミング要求にも応答できる性能強化が図られています。

v2.1.170へのアップデートを実施することで、この新モデルにアクセスできるようになります。

## 実用的な活用ポイント

Claude Fable 5の登場により、従来のモデルでは処理が困難だった複雑なコーディングタスクにも対応できるようになりました。高度なロジック構築や大規模なコードベースの解析など、より高い推論能力が求められる場面での活用が期待できます。

また、VS Code統合ターミナルからClaude Codeを起動していた場合にセッションが保存されない問題が解消されたため、ターミナル経由での利用時も作業履歴が適切に記録されるようになります。

## 全変更点一覧

| カテゴリ | 内容 | 概要 |
|---------|------|------|
| Feature | Claude Fable 5（Mythos級モデル）の一般提供 | 従来比で大幅に能力向上し、より複雑なコーディングタスクに対応可能に |
| Fix | VS Code統合ターミナルからの起動時のセッション保存バグ修正 | ターミナル経由で起動した際にセッションが保存されない問題を解消 |

## まとめ

本リリースでは、新しいMythos級モデルClaude Fable 5の提供開始という大きな機能追加と、VS Code統合ターミナル利用時の不具合修正が行われました。新モデルによる能力向上と、開発環境統合時の信頼性改善の両面で、Claude Codeの実用性が高まったリリースと言えます。
