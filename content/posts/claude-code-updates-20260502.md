# Claude Code v2.1.126 リリース情報

## はじめに

2026年5月2日、Claude Code v2.1.126 がリリースされました。本バージョンでは、ゲートウェイ互換性の強化、プロジェクト管理機能の追加、権限制御の柔軟化が主な変更点となっています。具体的には、モデルピッカーのゲートウェイエンドポイント対応、プロジェクト全体の履歴削除機能、権限プロンプトのスキップ機能が実装されました。また、Windows/WSL環境での認証・シェル検出の改善や、セキュリティ脆弱性の修正も含まれており、エンタープライズ環境での運用性が大きく向上しています。

## 注目アップデート深掘り

### ゲートウェイ互換性の強化：モデルピッカーのエンドポイント対応

今回のリリースで、モデルピッカーがゲートウェイのエンドポイントに対応しました。この変更は、企業のプロキシやAPIゲートウェイを経由してClaude Codeを利用する環境において重要な意味を持ちます。

従来、モデル選択時に直接Anthropic APIを参照する実装では、企業ネットワーク内部でゲートウェイを介してアクセス制御やログ記録を行う構成において、モデル情報の取得がうまく動作しないケースがありました。本アップデートにより、ゲートウェイ経由でのモデル一覧取得が可能になり、セキュアなネットワーク構成下でもスムーズにモデル選択ができるようになります。

この改善により、SREチームがAPIゲートウェイでトラフィックを一元管理しながら、開発者が通常通りモデルを切り替えて作業できる環境が整いました。特に、コンプライアンス要件の厳しい金融機関や医療機関など、すべてのAPI通信を監査ログに記録する必要がある組織にとって、この対応は運用上の大きな前進となります。

### プロジェクト全体の履歴削除機能の追加

新たにプロジェクト全体の履歴を一括で削除する機能が実装されました。これは、機密情報を含むプロジェクトの履歴管理や、ディスク容量の最適化において重要な機能です。

従来は個別の会話履歴を削除する必要があり、プロジェクト終了時や機密情報のクリーンアップに手間がかかっていました。本機能により、プロジェクト単位で履歴を一括削除できるため、セキュリティポリシーに沿った情報管理が容易になります。特に、顧客案件ごとにプロジェクトを分けて管理している場合、案件終了後に関連するすべての履歴を確実に削除できることは、GDPRや個人情報保護法などのコンプライアンス対応において不可欠です。

また、長期運用によって蓄積された履歴データによるストレージ圧迫を回避できるため、開発マシンのディスク管理の観点でも有用です。定期的なクリーンアップをスクリプト化することで、CI/CD環境での一時的なClaude Code利用後の確実なクリーンアップにも活用できます。

## 実用的な活用ポイント

今回のアップデートは、日常の開発ワークフローに次のような影響をもたらします。

**ゲートウェイ対応の活用**: 企業のプロキシ環境下で作業している場合、これまで発生していたモデル選択時のタイムアウトや接続エラーが解消される可能性があります。ネットワーク管理者と協力してゲートウェイの設定を確認し、適切なエンドポイント設定を行うことで、より安定した利用が可能になります。

**履歴管理の実践**: プロジェクトの履歴削除機能を活用し、案件ごとのライフサイクル管理を確立しましょう。特にSREやインフラエンジニアの場合、本番環境の設定情報やクレデンシャルを含む会話履歴が残らないよう、作業終了後に確実に削除する運用ルールを策定することを推奨します。また、定期的なクリーンアップをチームの標準手順に組み込むことで、セキュリティリスクを低減できます。

**Windows/WSL環境の改善**: Windows環境やWSLを利用している開発者は、認証やシェル検出の改善により、より円滑な動作を体験できるはずです。これまで認証エラーやシェル検出の不具合に悩まされていた場合は、本バージョンへのアップデートを優先して検討してください。

| Fix | セキュリティ修正 | 複数のセキュリティ脆弱性を修正 |

## まとめ

Claude Code v2.1.126は、エンタープライズ環境での運用性向上に重点を置いたリリースとなっています。ゲートウェイ対応により企業ネットワーク内での利用が円滑になり、履歴削除機能によってセキュリティとコンプライアンス対応が強化されました。また、Windows/WSL環境の改善は、多様な開発環境を持つチームにとって歓迎すべき変更です。

これらの変更は、Claude Codeが個人の開発ツールから、企業の本格的な開発基盤として採用されるために必要な成熟度を示しています。特にSREやインフラチームが安心してツールを展開できる基盤が整いつつあることは、今後の普及において重要なマイルストーンと言えるでしょう。セキュリティ修正も含まれているため、全ユーザーに早期のアップデートを推奨します。
