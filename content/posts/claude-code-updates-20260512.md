# Claude Code v2.1.139 リリース情報

## はじめに

2026年5月12日、Claude Code v2.1.139 がリリースされました。本バージョンでは、エージェント管理機能が大幅に強化され、開発生産性と透明性の向上が図られています。主な変更点は以下の通りです：

- 全セッションを一元管理できる新しい Agent View の追加
- `/goal` コマンドによる完了条件設定と自動複数ターン実行
- MCP stdio 対応の実装
- プラグイン詳細情報表示機能の追加
- トークンコスト推定精度の向上

## 注目アップデート深掘り

### Agent View による一元管理と /goal コマンドの自動実行

今回のリリースで最も注目すべきは、エージェント管理の抜本的な改善です。新しい Agent View により、複数のセッションを一つの画面から管理できるようになりました。これにより、並行して進行中のタスクを見失うことなく、効率的に作業を進められます。

さらに `/goal` コマンドが導入され、タスクの完了条件を事前に設定できるようになりました。この完了条件に基づき、エージェントは自動で複数ターンにわたって実行を継続します。これにより、開発者の手動介入を最小限に抑えながら、複雑なタスクを段階的に進めることが可能になります。

この機能により、長時間実行が必要な開発タスクや、複数ステップで構成される処理を、より自律的に実行できるようになります。

### MCP stdio 対応とプラグイン情報の透明性向上

MCP（Model Context Protocol）において、stdio 通信方式への対応が実装されました。これにより、プロセス間通信の選択肢が広がり、異なる環境やユースケースに柔軟に対応できるようになります。

またプラグイン詳細情報の表示機能が追加され、使用しているプラグインの仕様や動作をより詳細に把握できるようになりました。さらにトークンコスト推定の精度が向上したことで、実行前のコスト見積もりがより正確になり、予算管理やリソース計画が立てやすくなっています。

> **Note:** MCP（Model Context Protocol）は、Claude Code が外部ツールやデータソースと連携するための標準プロトコルです。

## 実用的な活用ポイント

今回のアップデートにより、以下のような開発シーンで生産性の向上が期待できます：

- **複雑なタスクの自動化**: `/goal` コマンドで完了条件を定義することで、コードレビュー対応やリファクタリングといった複数ステップが必要な作業を、エージェントに任せて進められます
- **マルチタスク管理**: Agent View により、複数のコードベースで並行作業している場合でも、各セッションの状態を俯瞰的に把握できます
- **コスト管理の最適化**: 改善されたトークンコスト推定により、実行前にコストを正確に見積もり、予算超過を防ぐことができます
- **プラグイン選定**: 詳細情報表示機能により、プラグインの仕様を事前に確認し、要件に合ったものを選択できます

これらの機能を組み合わせることで、Claude Code をより戦略的に活用し、開発フローに組み込むことが可能になります。

## まとめ

Claude Code v2.1.139 は、エージェント管理と自動化機能の大幅な強化に焦点を当てたリリースです。Agent View と `/goal` コマンドの組み合わせにより、複雑なタスクをより自律的に実行できるようになり、開発者の手動介入を減らしながら生産性を向上させることができます。

また MCP stdio 対応やプラグイン情報の透明性向上、コスト推定精度の改善により、Claude Code をプロダクション環境や大規模プロジェクトで活用する際の運用面も強化されています。特に予算管理やツール選定の場面で、より確実な判断材料が得られるようになったことは、業務利用において重要な改善と言えるでしょう。
