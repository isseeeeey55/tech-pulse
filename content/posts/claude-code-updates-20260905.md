## はじめに

2026年9月5日、Claude Code の v2.1.261 と v2.1.260 がリリースされました。v2.1.261 では、組織ポリシーのエラー表示改善、コマンド出力サイズの上限拡張（最大128K文字）、スキル診断機能の追加など、大規模な出力処理とスキル管理の強化が行われました。v2.1.260 では、フルスクリーンモードでの差分パネル追加、プロンプトキャッシュミスの原因表示、ファイルパーミッション処理の修正など、エディタ体験とセキュリティ面での改善が実施されています。両バージョンともに、Remote Control、クラウドセッション、認証周りの複数の不具合修正が含まれています。

## 注目アップデート深掘り

### コマンド出力サイズの大幅拡張（v2.1.261）

v2.1.261 では、`bashOutputMaxChars` と `taskOutputMaxChars` 設定が追加され、Claude が受け取るコマンド出力とバックグラウンドタスク出力の上限を最大128K文字まで引き上げられるようになりました。従来はこの上限を超える出力がファイルに保存されていましたが、設定により大量の出力を直接インラインで受け取ることが可能になります。これにより、複雑なコマンド実行やログ解析の結果を一度に確認でき、ファイル保存の中断を回避できます。

### スキル診断機能の追加（v2.1.261）

新たに追加された `/skill-doctor` コマンドにより、読み込まれたスキルのうち未使用のものや、各スキルがコンテキストに消費しているコストを確認できるようになりました。リリースノートには「so you can prune them」と記載されており、不要なスキルを削除してコンテキストを最適化する判断材料を提供します。

### 差分パネルの追加（v2.1.260）

v2.1.260 では、フルスクリーンモードでコミットされていない変更を会話の横に表示する差分パネルが追加されました。`/diff` コマンドでトグル可能で、Claude が編集を行う際の変更内容をリアルタイムで確認できます。

### プロンプトキャッシュミスの原因表示（v2.1.260）

`/cost` コマンドとステータス行の `prompt_cache` フィールドに、プロンプトキャッシュミスの発生理由（ツール定義やシステムプロンプトの変更、TTL超過など）が表示されるようになりました。キャッシュ効率の問題を診断しやすくなります。

## 実用的な活用ポイント

v2.1.261 の出力サイズ拡張により、大量のログやコマンド結果を扱う作業で、ファイル保存を挟まずに処理を継続できます。`/skill-doctor` でコンテキストコストを可視化し、不要なスキルを削除することで、Claude の応答精度と処理速度を向上できます。

v2.1.260 の差分パネルは、コード編集の変更内容を即座に確認したい場合に有用です。プロンプトキャッシュミスの原因表示は、キャッシュ効率が低下した際の原因特定を迅速化します。

両バージョンで多数のファイルパーミッション処理やクラウドセッション、Remote Control の不具合が修正されており、エンタープライズ環境やプロキシ経由での利用安定性が向上しています。
