## はじめに

Claude Code v2.1.195 がリリースされました。このバージョンでは、新しい環境変数によるマウス操作制御、フック・MCP サーバーの識別子マッチング修正を中心に、音声入力・プラグイン管理・バックグラウンドエージェントの安定性向上を含む計 12 件の変更が含まれています。

## 注目アップデート深掘り

### フックマッチャーのハイフン付き識別子の修正

今回のリリースで、`code-reviewer` や `mcp__brave-search` といったハイフン付き識別子を持つフックマッチャーが、意図せず部分文字列マッチしていた問題が修正されました。修正後は完全一致（exact-match）になり、ハイフン付き MCP サーバーの全ツールをマッチさせたい場合は `mcp__brave-search__.*` のようなパターンを使用する必要があります。

この変更により、フック設定でサーバー名を指定した際に、意図しない別のサーバーやツールが誤ってマッチする可能性が排除されました。特に複数の MCP サーバーを並行運用している環境では、予期しない動作を防ぐ重要な修正となります。

> **Note:** フックは Claude Code で特定のイベント（ツール実行、エージェント起動など）に対して処理を挿入できる機構です。MCP（Model Context Protocol）サーバーは外部ツールや検索エンジンなどを Claude に接続するプラグイン仕様です。

### 音声入力機能の多言語対応と macOS 安定性向上

音声入力機能に関して、日本語・中国語・タイ語など空白を使わない言語で自動送信（auto-submit）が発動しなかった不具合が修正されました。また macOS では、デフォルト入力デバイスが変更された後に長時間セッションで無音が録音される問題も解消されています。

さらに Linux 環境では、SoX がインストールされているが音声キャプチャデバイスが存在しない場合、「マイクがない」のか「SoX が未インストール」なのかを区別してエラーメッセージを表示するよう改善されました。これにより、ユーザーはトラブルシューティング時に原因を迅速に特定できます。

## 実用的な活用ポイント

フルスクリーンモードでホイールスクロールは維持しつつ、マウスクリックやドラッグ、ホバーを無効化したい場合は、新しく追加された `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` 環境変数を使用できます。

プラグイン管理の信頼性も向上しており、プロジェクト単位の `.claude/settings.json` で有効化されたプラグインが、ローダーパスごとに再インストール同意を要求されていた問題が修正されました。また `/plugin` コマンドで有効化・無効化する際、`plugin.json` の `name` がマーケットプレイス登録名と異なる場合でも正しく動作するようになりました。

バックグラウンドエージェントの運用では、クラッシュしたタスクを再度開いた際に最大 5 秒間空白画面が表示されていた問題が解消され、即座に再起動画面が表示されます。`claude agents` コマンドの完了リストも、利用可能な縦方向スペースを最大限活用するよう改善され、短いターミナルではヘッダーが圧縮されて実行中セッションが常に視認可能になります。

## まとめ

v2.1.195 は、フック識別子のマッチングロジック修正という重要な挙動変更と、音声入力・プラグイン管理・バックグラウンドエージェントに関する複数の不具合修正を含むメンテナンスリリースです。特にハイフン付き識別子の完全一致化は、MCP サーバーやフックを多用するワークフローに影響する可能性があるため、既存の設定を見直す必要があります。また音声入力の多言語対応改善やバックグラウンドジョブの安定性向上により、日常的な操作の信頼性が全体的に向上しています。
