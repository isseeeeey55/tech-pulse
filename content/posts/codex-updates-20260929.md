## はじめに

2026年9月29日、OpenAI Codex CLI の **rust-v0.158.0** がリリースされました。このバージョンでは、ユーザー体験の向上とセキュリティ強化に重点が置かれています。主な変更点として、TUIでのコピー&ペースト機能の強化（Markdownフォーマット保持）、MCP（Model Context Protocol）サーバーへのOAuth認証対応、exec-serverのWebSocket接続セキュリティ向上、画像生成における透明背景の明示的サポート、そして管理者権限での実行時におけるターミナル入力承認のデフォルト有効化などが含まれます。また、Windows、Linux、macOS各プラットフォームのサンドボックス関連の重要な不具合修正も実施されました。

## 注目アップデート深掘り

### TUIでのコピー機能強化とMarkdownフォーマット保持

今回のリリースでは、フルスクリーンTUIにおけるテキストコピー機能が大幅に改善されました（#47639, #47896, #48118）。具体的には、選択範囲のコピー時にMarkdownフォーマットが保持されるようになり、さらに「copy-on-select（選択時自動コピー）」と「right-click paste（右クリックペースト）」が設定可能になりました。

この変更が重要な理由は、エンジニアの日常的なワークフローにおいて、Codex CLIとの対話内容を他のドキュメントやコミュニケーションツールに転記するシーンが頻繁に発生するためです。従来、コードブロックや書式設定された内容をコピーする際、フォーマットが失われプレーンテキストになってしまう問題がありました。Markdownフォーマットの保持により、コピーした内容をそのままGitHub Issues、Slack、NotionなどのMarkdown対応ツールに貼り付けることができ、再編集の手間が大幅に削減されます。

設定については、リリースノートには設定可能であることが明示されていますが、具体的な設定方法の詳細は記載されていません。copy-on-selectとright-click pasteが個別に制御できる仕様であることから、TUIの設定セクションでこれらのオプションを有効化できると考えられます。

この改善により、特にドキュメント作成やコードレビュー、インシデント対応時の情報共有といった場面で、Codexとの対話内容を効率的に活用できるようになります。

### MCP ServerへのOAuth認証サポート拡充

本バージョンでは、事前登録されたOAuthクライアントシークレットを必要とするMCPサーバーへの接続がサポートされました（#47891）。これにより、`codex mcp add --oauth-client-secret` コマンドを使用してクライアントシークレットを指定できるようになりました。

> **Note:** MCP（Model Context Protocol）は、Codex CLIが外部ツールやサービスと連携するためのプロトコルです。MCPサーバーを追加することで、Codexの機能を拡張できます。

この機能追加の背景には、エンタープライズ環境におけるセキュリティ要件の高まりがあります。多くの組織では、外部サービスへのアクセスに際して、OAuth 2.0による認証と事前登録されたクライアント認証情報の使用を義務付けています。従来のMCP接続では、こうした厳格な認証要件を満たすサーバーへの接続が困難でしたが、今回のアップデートによりエンタープライズグレードのセキュリティポリシーに準拠したMCPサーバーとの連携が可能になりました。

具体的な使用例として、リリースノートには `codex mcp add --oauth-client-secret` というコマンドフラグが明示されています。これにより、組織のセキュリティチームから提供されたクライアントシークレットを使用して、承認されたMCPサーバーのみに接続できるようになります。

SREやインフラエンジニアの視点では、この機能により社内の監査ツール、モニタリングシステム、インシデント管理プラットフォームなど、セキュアなMCPサーバーをCodexに統合できるようになります。これにより、Codexを使った運用自動化の範囲が大幅に広がります。

## 実用的な活用ポイント

今回のリリースは、日常的な開発ワークフローに複数の改善をもたらします。

**TUIでの作業効率化**: Markdownフォーマットを保持したコピー機能により、Codexとの対話内容をドキュメントに転記する作業が効率化されます。インシデント対応時のポストモーテム作成や、設計ドキュメントへのコード例追加など、頻繁に発生するタスクの時間短縮が期待できます。copy-on-selectを有効化すれば、マウスで選択するだけで自動的にクリップボードにコピーされるため、さらにスピードアップが可能です。

**セキュアなMCP連携**: エンタープライズ環境で作業するエンジニアにとって、OAuth認証対応は重要な前進です。社内のセキュリティポリシーに準拠しながら、Codexの機能を拡張できるようになります。SREの観点では、監視ダッシュボードやアラートシステムとの連携がセキュアに実現可能になります。

**権限管理の改善**: 管理者権限での実行時にターミナル入力承認がデフォルトで有効化されたこと（#47799）により、意図しない権限昇格を防げます。また、runtime-only権限付与時には不要なレビューが発生しなくなり（#48073）、承認プロセスが最適化されました。これにより、セキュリティを維持しながらも作業の流れが改善されます。

**プラットフォーム固有の安定性向上**: Windows、Linux、macOSそれぞれでサンドボックス関連の不具合が修正されており、クロスプラットフォーム環境で作業するチームにとって重要なアップデートです。特にWindows 10での通常パス処理の修正（#47672）や、Linuxでのネストされた書き込み可能ルートの起動問題修正（#47623）は、安定した開発環境の維持に貢献します。

## まとめ

rust-v0.158.0は、ユーザー体験、セキュリティ、安定性の三つの軸でバランスの取れたアップデートとなっています。TUIでのコピー機能強化やMarkdownフォーマット保持は、日常的な作業効率を着実に向上させる改善です。MCP OAuthサポートとWebSocketセキュリティ強化は、エンタープライズ環境での採用を加速させる重要な機能追加と言えます。

また、各プラットフォームでのサンドボックス不具合修正や、Guardian認証コンテキストの改善など、内部基盤の品質向上にも注力されています。150以上のコミットが含まれており、大小さまざまな改善が積み重ねられたリリースです。

特にSREやインフラエンジニアにとっては、セキュアなMCP連携の実現と、権限管理の改善により、運用自動化の範囲を広げつつも安全性を維持できる環境が整いました。今後のリリースでも、こうした実用性とセキュリティのバランスを取ったアップデートが継続されることが期待されます。
