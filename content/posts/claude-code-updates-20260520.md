## はじめに

2026年5月20日、Claude Code の v2.1.145 と v2.1.144 がリリースされました。今回のリリースでは、Claude Agents のセッション管理機能の強化、モデル選択の細粒度制御、そしてセキュリティ面での重要な修正が含まれています。バックグラウンドセッション管理、ネットワーク接続問題への耐性向上、ターミナル UI の改善により、長時間運用での安定性が向上しています。

## 注目アップデート深掘り

### Claude Agents のセッション管理強化と JSON 出力対応

v2.1.145 では Claude Agents のセッション管理機能が強化され、JSON 出力によるスクリプト化対応が実現されました。これにより、CI/CD パイプラインや自動化ワークフローへの組み込みが容易になります。同時に OTEL スパンのトレーシングが改善され、Agent の動作を詳細に追跡できるようになりました。

バックグラウンドセッション管理機能（v2.1.144）と組み合わせることで、長時間実行される Agent タスクをより柔軟に制御できます。プラグイン検出画面も充実し、利用可能な拡張機能の把握が容易になりました。

### セキュリティ修正：権限プロンプトのバイパス脆弱性

v2.1.145 では、権限プロンプトのバイパス脆弱性と環境変数の権限チェック問題が修正されました。これらの脆弱性は、意図しない操作や情報漏洩につながる可能性があったため、セキュリティ要件の厳しい環境で運用しているユーザーにとって重要な修正です。

この修正により、Claude Code が要求する権限の制御がより確実になり、企業環境での安全な運用が強化されています。

## 実用的な活用ポイント

今回のリリースでは、安定性とセキュリティの両面で実用性が向上しています。

v2.1.145 の JSON 出力対応により、Claude Agents を自動化スクリプトに統合する際の柔軟性が増しました。セキュリティ修正は即座に適用することを推奨します。特に環境変数に機密情報を含む運用をしている場合は、権限チェック問題の修正が重要です。

v2.1.144 のモデル選択の細粒度制御は、タスクの性質に応じて最適なモデルを使い分けたい場合に有用です。ネットワーク接続問題への耐性向上と macOS でのクラッシュ解決により、不安定なネットワーク環境や長時間のセッションでも安定した動作が期待できます。

## まとめ

v2.1.145 と v2.1.144 は、機能拡張よりも安定性とセキュリティの向上に焦点を当てたリリースです。特にセキュリティ修正は重要度が高く、早期のアップデートが推奨されます。

バックグラウンドセッション管理とネットワーク耐性の向上により、長時間運用やリモート環境での利用体験が改善されています。JSON 出力対応による自動化の促進と、モデル選択の細粒度制御により、より柔軟な運用が可能になりました。全体として、エンタープライズ環境での実用性を高める堅実なアップデートと言えるでしょう。
