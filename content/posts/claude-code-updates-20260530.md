# Claude Code v2.1.157・v2.1.156 リリース情報

## はじめに

2026年5月30日、Claude Codeの2つのバージョンがリリースされました。v2.1.157ではローカルプラグインの自動読み込み機能、エージェント管理の改善、ワークツリー操作の強化など開発体験を向上させる複数の機能追加とバグ修正が含まれています。v2.1.156ではClaude Opus 4.8使用時の思考ブロック関連の不具合が修正されました。

## 注目アップデート深掘り

### ローカルプラグイン自動読み込みとプラグイン初期化コマンド

v2.1.157ではローカルプラグインの自動読み込み機能が追加され、プラグイン初期化コマンドも新たに導入されました。これによりプラグイン開発者はセットアップの手順を簡素化でき、開発環境の立ち上げが迅速化されます。エージェント管理においてはエージェント設定の尊重が改善され、バックグラウンドエージェントのセッション管理に関する複数のバグや、ネットワークパーミッション周りのバグが修正されています。

### Claude Opus 4.8における思考ブロックの不具合修正

v2.1.156では、Claude Opus 4.8を使用する際に思考ブロック（thinking blocks）が不正に変更されてAPIエラーが発生する問題が修正されました。この修正により、高度な推論能力を必要とする複雑なコード生成タスクが安定して実行できるようになります。思考ブロックはモデルの推論プロセスを表現する機能であり、この不具合が解消されたことで、Opus 4.8の能力を最大限に活用できるようになりました。

> **Note:** 思考ブロックは、Claude が複雑な問題を段階的に推論する際の内部プロセスを表現する機能です。

## 実用的な活用ポイント

ローカルプラグインの自動読み込みとプラグイン初期化コマンドの追加により、プラグインを活用したカスタマイズがより手軽になります。特にチーム開発においては、プラグイン環境の統一が容易になるでしょう。

エージェント設定の尊重やセッション復帰時の日付同期修正により、長時間のセッションや複数エージェントを使用する場合の信頼性が向上しています。ワークツリー操作の強化も含め、日常的な開発フローがよりスムーズになることが期待できます。

Claude Opus 4.8を使用する場合は、v2.1.156以降へのアップデートが推奨されます。特に複雑なコード生成タスクにおいて、思考ブロック関連のエラーが解消されることで安定性が向上します。

## まとめ

今回のリリースは、開発体験の向上と信頼性の強化に焦点が当てられています。v2.1.157ではプラグイン機能の使い勝手向上とエージェント管理の改善により、日常的な開発ワークフローがより快適になります。v2.1.156では高性能モデルであるClaude Opus 4.8の安定性が向上し、複雑なタスクにおける信頼性が改善されました。特にバックグラウンドエージェントやセッション管理に関する複数のバグ修正が含まれており、長時間の作業セッションでも安心して利用できる環境が整備されています。
