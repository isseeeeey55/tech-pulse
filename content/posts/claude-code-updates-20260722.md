## はじめに

Claude Code v2.1.217 がリリースされました。本バージョンでは、絵文字ショートコードの自動補完機能が追加され、トランスクリプト書き込み失敗時の警告が導入されました。同時に、MCP ツール出力に関するメモリリーク、Windows 自動更新の失敗処理、セッション隔離の symlink 正規化、mTLS/OAuth 設定の無視、スクリーンリーダーモードの不具合、サブエージェントの予算制御など、多岐にわたるバグ修正が実施されています。

## 注目アップデート深掘り

### 絵文字ショートコード自動補完の追加

プロンプト入力時に `:heart:` と入力すると ❤️ が挿入され、`:hea` のように途中まで入力すると候補が表示されるようになりました。この機能は `emojiCompletionEnabled` 設定で無効化できます。プロンプト内に視覚的なマーカーや感情表現を含めたい場面で、絵文字名を記憶していなくても直感的に入力できるため、コミュニケーションの表現力が向上します。

### トランスクリプト書き込み失敗時の警告

ディスクフルなどでトランスクリプト書き込みが失敗する場合や、環境変数の影響でセッション保存がオフになっている場合に、警告が表示されるようになりました。これまではトランスクリプトがサイレントに失われていましたが、警告が追加されたことで、作業履歴の喪失を事前に防げるようになります。長時間のセッションや重要な操作記録を保持したい場面で、データ損失リスクを早期に検知できる点が重要です。

### MCP ツール出力のメモリリーク修正

切り詰められた MCP ツール出力が、セッション終了まで内部で完全な未切り詰め結果をメモリ上に保持し続ける問題が修正されました。長時間稼働するセッションや大量のツール出力を扱う場面で、メモリ消費が蓄積する原因となっていましたが、本修正によりメモリ使用量が適切に管理されるようになります。

> **Note:** MCP (Model Context Protocol) は Claude Code が外部ツールと連携するためのプロトコルです。

## 実用的な活用ポイント

- **絵文字ショートコード**: プロンプトにマーカーやステータスを視覚的に埋め込みたい場合、`:` で始まるショートコード入力が利用できます。不要な場合は `emojiCompletionEnabled` で無効化可能です。
- **トランスクリプト保存の監視**: ディスク容量不足や環境変数の誤設定によるトランスクリプト損失を、警告で事前に検知できるようになりました。重要な作業履歴を扱う場合は、警告が出ないか定期的に確認することが推奨されます。
- **サブエージェント制御**: デフォルトで同時実行サブエージェントは 20 に制限され、ネスト生成もデフォルトで無効化されました。`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` と `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` で調整可能です。`--max-budget-usd` を超えた場合、バックグラウンドサブエージェントも停止されるようになり、予算管理が厳密化されました。

## 全変更点一覧

| カテゴリ | 内容 | 概要 |
|---------|------|------|
| Feature | 絵文字ショートコード自動補完 | `:heart:` で ❤️ を挿入、`:hea` で候補表示。`emojiCompletionEnabled` で無効化可能 |
| Feature | トランスクリプト書き込み失敗時の警告 | ディスクフルや環境変数でセッション保存がオフの場合に警告を表示 |
| Fix | MCP ツール出力のメモリリーク | 切り詰められた出力が完全な結果をメモリ保持し続ける問題を修正 |
| Fix | Windows 自動更新失敗時の復旧 | 更新失敗で `claude.exe` が消失する問題を修正し、自動復元を実装 |
| Fix | セッション隔離の symlink 正規化 | バックグラウンドセッション隔離が symlink を正規化せず、ワークスペースを脱出できる問題を修正 |
| Fix | Claude Opus 4.8 on Bedrock での自動コンパクト | 自動コンパクトがトリガーされず、`/compact` が制限超過時に失敗する問題を修正 |
| Fix | Claude Desktop セッションでの mTLS/OAuth 設定無視 | 企業 mTLS、TLS-verify、OAuth スコープ、プロキシ設定が無視される問題を修正 |
| Fix | スクリーンリーダーモードのアナウンス中断 | 起動アナウンスが最初のプロンプトレンダリングで切断される問題、および thinking ステータス行の頻繁な再レンダリングを修正 |
| Fix | マネージド設定での OTEL エンドポイント | `OTEL_EXPORTER_OTLP_ENDPOINT` が全シグナルを管理せず、下位スコープのオーバーライドでテレメトリが別エンドポイントに向く問題を修正 |
| Fix | `--resume`/`--continue` での TypeError | トランスクリプトに不正な添付エントリがある場合に発生する TypeError を修正 |
| Fix | Remote Control セッションの許可プロンプト表示 | プロンプト表示後に接続した視聴者に許可ダイアログが表示されない問題を修正 |
| Fix | バックグラウンドシェルの停止不能 | `/background` やセッション終了時、負荷の高いマシンでシェルが停止不能になる問題を修正（特に Windows） |
| Fix | `CLAUDE.md`/`SKILL.md` の brace 展開 OOM | 多数のブレースグループを含む paths frontmatter 値が CLI 起動時に OOM やストールを引き起こす問題を修正。brace 展開に予算制限を導入 |
| Fix | バックグラウンドセッション接続時のトランスクリプトプレビュー配置 | 起動中のバックグラウンドセッションに接続時、トランスクリプトプレビューが入力エリアに密着する問題を修正 |
| Improvement | フッター PR バッジのハイパーリンク | ターミナルサポートが検出できない環境（ssh/tmux 越し）でもクリック可能に。`FORCE_HYPERLINK=0` で無効化可能 |
| Improvement | ログイン期限切れ警告タイミング | 期限の 5 日前から 3 日前に変更 |
| Improvement | frontend-design プラグイン提案の表示回数制限 | 無制限だった表示を生涯 3 回に制限 |
| Improvement | サブエージェント同時実行数の上限 | デフォルト 20 に制限（`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` でオーバーライド可能） |
| Improvement | サブエージェントのネスト生成無効化 | デフォルトでネスト生成を禁止。`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` で許可可能 |
| Fix | `--max-budget-usd` のバックグラウンドサブエージェント制御 | 予算上限到達時、新規サブエージェント生成を拒否し、実行中のバックグラウンドエージェントを停止 |

## まとめ

v2.1.217 は、絵文字ショートコード自動補完とトランスクリプト書き込み失敗時の警告という 2 つの新機能に加え、メモリリーク、Windows 自動更新、セッション隔離、mTLS/OAuth 設定、スクリーンリーダーモード、サブエージェント制御など、広範なバグ修正と信頼性改善が実施されたリリースです。特にメモリ管理、設定の反映、バックグラウンドプロセスの制御といった基盤部分の安定性が強化されており、長時間稼働やセキュアな環境での運用品質向上が期待できます。
