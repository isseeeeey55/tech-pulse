# Claude Code v2.1.169 リリース情報

## はじめに

2026年6月9日、Claude Code v2.1.169 がリリースされました。本バージョンでは、トラブルシューティング用の**安全モード**（`--safe-mode`）の追加、セッション中のディレクトリ移動を可能にする `/cd` コマンドの実装が行われました。また、MCP設定の強制機能の改善によりエンタープライズ管理ポリシーの適用が確実になり、UI応答性の向上とWindows/macOS/WSLにおける複数のバグ修正により、CLI操作の安定性が大幅に改善されています。

## 注目アップデート深掘り

### 安全モード（--safe-mode）によるトラブルシューティング強化

新たに追加された `--safe-mode` フラグは、問題発生時の診断・切り分けを支援するトラブルシューティング機能です。Claude Code の動作に問題が生じた際、このモードで起動することで最小限の設定で動作を確認できるようになります。

エンタープライズ環境では複雑な設定や拡張機能が組み合わさることが多く、問題の原因特定が困難なケースがあります。安全モードは、こうした状況下で問題の切り分けを迅速に行うための手段として提供されます。

### /cd コマンドによるセッション内ディレクトリ移動

セッション中に作業ディレクトリを変更できる `/cd` コマンドが実装されました。従来はセッション開始時のディレクトリに固定されていましたが、対話中に異なるプロジェクトディレクトリへ移動する必要が生じた場合でも、セッションを再起動することなく作業を継続できるようになります。

これにより、複数プロジェクトにまたがる作業や、セッション中に作業対象を切り替える必要がある場合の操作性が向上します。

## 実用的な活用ポイント

トラブルシューティングの際は、まず `--safe-mode` フラグを使用して問題を再現できるかを確認することで、設定起因の問題かClaude Code本体の問題かを切り分けられます。

複数のプロジェクトを横断して作業する場合、`/cd` コマンドを活用することでセッションを維持したまま作業ディレクトリを切り替えられ、コンテキストを失わずに効率的な作業が可能になります。

エンタープライズ環境では、MCP設定の強制機能改善により、組織の管理ポリシーが確実に適用されるようになったため、コンプライアンス要件を満たしつつClaude Codeを運用できます。

## 全変更点一覧

| カテゴリ | 内容 | 概要 |
|---------|------|------|
| Feature | 安全モード追加 | `--safe-mode` フラグによるトラブルシューティング機能 |
| Feature | /cd コマンド実装 | セッション中のディレクトリ移動が可能に |
| Improvement | MCP設定の強制改善 | エンタープライズ管理ポリシーの確実な適用 |
| Improvement | UI応答性向上 | CLI操作の応答速度改善 |
| Fix | Windows/macOS/WSL バグ修正 | 複数プラットフォームでの安定性向上 |

> **Note:** MCP（Model Context Protocol）は、Claude Code が外部ツールやデータソースと統合するための仕組みです。

## まとめ

v2.1.169 は、トラブルシューティング機能と操作性の両面で実用的な改善が行われたリリースです。安全モードの追加により問題診断の効率が向上し、`/cd` コマンドにより作業の柔軟性が増しました。また、MCP設定の強制機能改善とマルチプラットフォームでのバグ修正により、エンタープライズ環境での安定運用がさらに強化されています。
