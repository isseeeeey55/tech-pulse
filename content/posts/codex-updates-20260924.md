# OpenAI Codex CLI rust-v0.156.1 リリース情報

## はじめに

2026年9月24日、OpenAI Codex CLI の rust-v0.156.1 がリリースされました。本バージョンは、hotfix として位置づけられるマイナーアップデートで、主な変更点は新しい大規模言語モデル **GPT-6 Sol** と **GPT-6 Luna** のサポート追加です。モデルピッカーから両モデルを選択できるようになり、rate-limit 切り替えプロンプトでは GPT-6 Luna が推奨モデルとして表示されるようになりました。

この変更により、ユーザーは最新の GPT-6 シリーズモデルを Codex CLI から直接利用できるようになり、コード生成タスクにおけるモデル選択の柔軟性が向上しています。

## 注目アップデート深掘り

### GPT-6 Sol と GPT-6 Luna のモデルカタログ追加

本リリースの中心的な変更は、GPT-6 シリーズの2つの新モデル **Sol** と **Luna** がモデルピッカーに追加されたことです。これは PR #47405 として実装され、前バージョン rust-v0.156.0 に対する hotfix として提供されています。

**なぜこの変更が重要なのか**

モデルカタログへの追加は、単なるモデル選択肢の増加以上の意味を持ちます。特に注目すべきは、rate-limit 切り替え時のプロンプトで **GPT-6 Luna が推奨モデルとして表示される**ようになった点です。これは、OpenAI が Luna を rate-limit に達したユーザーに対する最適な代替モデルとして位置づけていることを示唆しており、コスト効率や応答性のバランスが取れたモデルである可能性が高いと考えられます。

**実際の利用方法**

Codex CLI のモデルピッカーを起動すると、従来のモデルに加えて GPT-6 Sol と GPT-6 Luna が選択肢として表示されます。rate-limit に達した際には、システムが自動的に Luna への切り替えを推奨するプロンプトを表示するため、ユーザーは中断なくコード生成タスクを継続できます。

この変更により、高負荷な開発作業中でも、モデルを柔軟に切り替えながらワークフローを維持できるようになりました。Sol と Luna という2つの選択肢が提供されることで、タスクの性質やコスト要件に応じた使い分けが可能になります。

> **Note:** モデルピッカーは Codex CLI のインタラクティブモードで起動できる機能で、タスクに応じて使用する GPT モデルを選択できます。

## 実用的な活用ポイント

本リリースは hotfix としての位置づけですが、日常の開発ワークフローに即座に影響を与える重要な更新です。

**すぐに試せる Tips**

- モデルピッカーを起動して、GPT-6 Sol と Luna の両方を試し、コード生成の品質や応答速度を比較してみましょう。特に、複雑なロジックを含むコード生成タスクや、大量のコンテキストを必要とする場面で違いが現れる可能性があります。
- rate-limit に達した際には、Luna への切り替え推奨プロンプトに従うことで、スムーズにタスクを継続できます。

**SRE/インフラエンジニアの視点での活用**

Infrastructure as Code（IaC）の記述や、運用自動化スクリプトの生成において、モデル選択の柔軟性は重要です。例えば、Terraform や CloudFormation のリソース定義を生成する際、rate-limit を気にせず作業を継続できることは、タイトなスケジュールでのインフラ構築において大きなメリットとなります。また、CloudWatch Logs の分析スクリプトや AWS CLI を使った自動化コードの生成時にも、Luna への切り替えによって中断なく作業を進められます。

## まとめ

rust-v0.156.1 は、hotfix としての性格が強いリリースでしたが、GPT-6 シリーズの Sol と Luna という最新モデルへのアクセスを提供する重要なアップデートです。特に Luna が rate-limit 時の推奨モデルとして位置づけられている点は、長時間のコード生成タスクやチーム開発における利便性を大きく向上させます。

モデルカタログの拡充は、Codex CLI がより多様な開発シーンに対応できる柔軟性を持ったツールへと進化していることを示しています。日常的なコード生成からインフラ構築まで、幅広い場面で新モデルの恩恵を受けられるでしょう。
