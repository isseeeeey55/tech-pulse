# Claude Code v2.1.235 リリース情報

## はじめに

Claude Code v2.1.235 がリリースされました。このバージョンでは、新たにスペルチェック機能が追加されたほか、プロンプト入力やダイアログ周りの UI 改善、バックグラウンド実行時のリソース使用量削減など、多岐にわたる機能改善と不具合修正が行われています。

## 注目アップデート深掘り

### スペルチェック機能の追加

プロンプト入力時にスペルミスを検出して下線表示する `spellcheck` 設定が追加されました。この機能は、システムにインストールされている `aspell`、`hunspell`、または `ispell` を利用します。オプション設定であるため、必要に応じて有効化することで、プロンプト入力の精度を高めることができます。

### バックグラウンド実行時のリソース使用量改善

`/ultrareview` や `/autofix-pr` などのクラウドセッションがバックグラウンドで実行されている際のメモリと CPU 使用量が改善されました。従来は更新のたびにイベントストリームが再スキャン・再レンダリングされていましたが、この処理が不要になったことで、リソース効率が向上しています。

## 実用的な活用ポイント

今回のリリースでは、日常的な操作性の向上が多く含まれています。スペルチェック機能により入力ミスを早期に発見できるほか、複数行プロンプトでのハイライト位置ずれや Shift+Tab の誤動作など、細かな UI の不具合が修正されています。また、バックグラウンドで重い処理を実行する際のリソース効率が改善されたことで、複数セッションの並行実行がより安定します。権限ダイアログの改善により、承認対象の内容とオプションが正確に表示されるようになり、安全性も向上しています。

## 全変更点一覧

| カテゴリ | 内容 | 概要 |
|---------|------|------|
| Feature | スペルチェック設定の追加 | プロンプト入力時に `aspell`、`hunspell`、または `ispell` を使ってスペルミスを下線表示するオプション設定を追加 |
| Fix | プロンプトキャッシュ無効化の修正 | 言語サーバーが切断・再接続した際に whole-prompt-cache が不正に無効化される問題を修正 |
| Fix | マークダウンリスト表示の修正 | ネストされたリスト項目が深さ 3 以上で位置ずれする問題と、折り返し時のぶら下げインデントを修正 |
| Fix | プロンプト入力ハイライトのずれ修正 | 複数行プロンプトでスラッシュコマンド、キーワード、メンションのハイライトが 1 文字以上ずれる問題を修正 |
| Fix | Shift+Tab 誤動作の修正 | 権限プロンプトのコメントフィールド内で Shift+Tab を押すとフィールドを閉じる代わりに編集承認とセッション全体の編集許可が付与される問題を修正 |
| Fix | Agent ツールのエラーメッセージ改善 | 利用不可能なエージェントがデフォルトとして広告される問題を修正し、`subagent_type` 省略時に利用可能なエージェント一覧を示す明確なエラーを表示 |
| Fix | ノートブックセル削除/置換ダイアログの改善 | ノートブックやセルが読み取れない場合に既存セル内容を黙って省略する問題を修正し、理由を表示 |
| Fix | スラッシュコマンド表示の修正 | Claude 応答中にスラッシュコマンドを実行すると HTML エンティティが表示される問題を修正 |
| Fix | 更新通知の修正 | バックグラウンド自動更新後にプロンプトフッターに "Update installed" 再起動通知が表示されない問題を修正 |
| Fix | タスクリスト展開状態の修正 | 開いたタスクが残っているセッションを再開・再起動する際に拡張タスクリスト（ctrl+t）が常に折りたたまれた状態で開始される問題を修正 |
| Improvement | バックグラウンドセッションのリソース使用量削減 | `/ultrareview` や `/autofix-pr` などのクラウドセッションがバックグラウンド実行中のメモリと CPU 使用量を改善（イベントストリームの再スキャン・再レンダリングを廃止） |
| Improvement | 権限ダイアログの改善 | 表示テキストと "don't ask again" オプションが常に許可される範囲と一致し、内容を完全に表示できない場合は "don't ask again" を非表示に |
| Improvement | 組み込み grep の改善 | ネイティブ macOS/Linux ビルドで病的なパターンがメモリを使い果たす代わりに高速失敗し、`-m N` と `-A/-C` の組み合わせで正しいコンテキストを出力 |
| Improvement | コンテキスト制限エラーの改善 | auto-compact がオフの場合にその旨を表示し、`/config` で再有効化できることを案内 |
| Improvement | Vim モードの改善 | 詳細トランスクリプト切り替え（ctrl+o）やパネル閉じる際に NORMAL モードとカーソル位置を保持 |
| Improvement | ダイアログ操作の改善 | 矢印キーと Enter を素早く押した際に、以前にハイライトされていた選択肢ではなく、移動先の選択肢が選択されるように改善 |
| Improvement | SendMessage の改善 | クロスセッション配信には大きすぎるメッセージを黙ってドロップする代わりに事前に拒否 |
| Improvement | Remote Control の改善 | `claude rc` が対話型起動と同じエンタープライズゲートウェイ可用性チェックを適用 |
| Fix | [VSCode] フォーカスジャンプの修正 | 複数の Claude パネルを持つウィンドウが復元またはリロードされた際に、開いている Claude タブ間でフォーカスが勝手に移動する問題を修正 |

## まとめ

v2.1.235 は、スペルチェック機能の追加を含む機能強化と、プロンプト入力・ダイアログ UI・バックグラウンド処理など幅広い領域での不具合修正が実施されたバージョンです。特にバックグラウンドセッションのリソース効率改善や、細かな操作時の不具合修正により、日常的な利用体験の安定性と快適性が向上しています。
