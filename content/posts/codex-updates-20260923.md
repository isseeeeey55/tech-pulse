## はじめに

OpenAI Codex CLI の **rust-v0.156.0** がリリースされました。本バージョンは、ユーザー体験を大きく変える大型アップデートです。特に注目すべきは、オプションのフルスクリーン UI（`/tui`）の導入、音声会話機能のデフォルト有効化、アカウント使用状況を可視化する `/usage` 分析ダッシュボードの追加です。さらに、タスク管理機能の強化（ステータスフィルタ、worktree セッション作成）、6つの新しいテーマ、Mermaid 図やTeX数式のターミナル内レンダリング対応、ローカルバックグラウンドサーバーを `/daemon` で更新できる機能なども盛り込まれています。

バグ修正も充実しており、ストリーミング中の回答やプランが中断・失敗時にも保持されるようになったほか、tmux/SSH環境でのクリップボード転送、Plan モードの復元、MCP認証のリフレッシュ処理、サンドボックスの分離強化など、安定性とセキュリティが大幅に向上しています。このリリースは100件を超える変更を含み、開発者の日常ワークフローを幅広く改善する内容となっています。

## 注目アップデート深掘り

### 1. フルスクリーン TUI（`/tui`）による対話体験の進化

本リリースでは、新たに **オプションのフルスクリーン UI** が `/tui` コマンドで利用可能になりました。これは単なる表示オプションの追加ではなく、ターミナル内での Codex 操作を根本的に変える機能です。リリースノートには「次回起動時にフルスクリーン UI を選択可能。transcript search、マウス選択、右クリックコピーなどを含む」と記載されており、複数の PR（#46732, #46734, #46883, #46895）を通じて段階的に実装されました。

**なぜ重要なのか:**  
従来のインラインストリーム形式では、長い会話履歴の検索や過去のやり取りの参照が困難でした。フルスクリーンモードでは、transcript（会話履歴）全体をスクロール可能な専用ビューで表示し、検索機能とマウスによる選択・コピーをサポートします。これにより、エンジニアが過去のコード生成結果やエラーメッセージを素早く参照し、知見を再利用するワークフローが劇的に効率化されます。

**具体的な使い方:**

```bash
$ codex /tui
```

このコマンドを実行すると、次回の Codex CLI 起動時にフルスクリーン UI モードが有効になります。起動後は、transcript ビューアで会話全体を閲覧でき、Ctrl+F（キーマップ依存）などで検索、マウスドラッグで選択、右クリックでクリップボードへコピーが可能です。また、`/tui` は起動前の設定変更であり、セッション中にモードを切り替えるものではない点に注意が必要です。

リリースノートには「Align persisted TUI activity groups and reasoning with live output」「Add compact transcript browsing and prompt navigation to the TUI」といった記述もあり、過去の会話が保存され、ライブ出力と同じスタイルで再現される仕組みも整備されています。これにより、長期プロジェクトでの知識蓄積とコンテキスト管理が大幅に改善されます。

### 2. 音声会話機能のデフォルト有効化と F8 トグル

音声会話機能が **デフォルトで有効化** され、F8 キーによるトグルと `/voice settings` による音声選択が可能になりました。さらに、Linux と Windows 向けの音声ランタイムがバンドルされ、追加インストール不要で利用できるようになっています（#44921, #46071, #44622, #44714, #44922）。

**なぜ重要なのか:**  
音声による対話は、コーディング中にキーボードから手を離さずに質問やコマンドを発行できるメリットがあります。特に、デバッグ中や設計を考えながらコードを書く場面で、テキスト入力を中断せずに Codex と対話できることは、思考フローの維持に大きく貢献します。従来は手動で有効化が必要でしたが、デフォルト化により初回起動時から利用可能になり、導入障壁が下がりました。

**具体的な使い方:**

```bash
# 音声会話の有効/無効を切り替え（セッション中に F8 を押下）
# または音声設定を事前に選択
$ codex /voice settings
```

リリースノートには「Keep voice sessions alive through mute and audio backlog」「Preserve voice playback across pauses and packet bursts」といった記述があり、音声ミュート中やオーディオバッファの蓄積時でもセッションが途切れず、再生が安定する改善が行われています。また「Bundle native voice runtimes in Windows releases」により、Windows ユーザーも追加の依存関係インストールなしで音声機能をすぐに試せます。

> **Note:** 音声機能には Codex CLI がマイク入力と音声出力へアクセスする権限が必要です。初回起動時に許可を求められる場合があります。

## 実用的な活用ポイント

### 日常の開発ワークフローへの影響

本リリースは、Codex CLI を日常的に使うエンジニアにとって、以下のような実用的な改善をもたらします。

- **`/usage` アカウント分析ダッシュボード** により、トークン使用量、プラグイン・スキルのアクティビティを可視化できます（#45764, #45769）。これにより、API クォータを意識した使い方が可能になり、コスト最適化や使用傾向の把握が容易になります。特にチームで Codex を共有している場合、誰がどの機能を多用しているかを把握し、ベストプラクティスを共有する材料にできます。

- **worktree セッション作成とステータスフィルタ** がエージェントコマンドセンターに追加されました（#46839, #45276, #44870）。Git worktree を活用した並行作業が Codex から直接管理でき、タスクをステータスごとにフィルタすることで、複数ブランチでの開発やレビュー対応がスムーズになります。

- **6つの新テーマと Mermaid 図・数式表示** により、ターミナル上での視認性と情報伝達が向上しました（#46504, #46054, #45612）。Mermaid によるフローチャートやシーケンス図がターミナル内で直接表示されるため、設計ドキュメントを別ウィンドウで開く必要がなくなり、Codex の提案内容を即座に図で確認できます。数式も Unicode 表記でレンダリングされ、数学的なアルゴリズムの説明が読みやすくなります。

### SRE/インフラエンジニアの視点での活用シーン

- **`/daemon` によるローカルバックグラウンドサーバー更新** と `--no-daemon` オプション（#45854, #46088）により、長時間稼働するサーバー環境での Codex CLI 運用が柔軟になりました。SRE が本番環境の調査中に Codex を常駐させたい場合、daemon 経由で安定稼働させつつ、必要に応じて `--no-daemon` で独立プロセスとして起動できます。

- **サンドボックス分離の強化**（#44639, #45984, #46500）により、Windows の inbound 接続、Linux/macOS の特権ソケット、macOS の読み取り専用ファイルハンドル経由の書き込みが遮断されるようになりました。これにより、Codex が生成したコードを安全に実行でき、インフラ変更スクリプトのテストやデバッグを本番環境に影響を与えずに行えます。

- **tmux/SSH セッションでのクリップボード転送修正**（#45457, #45454）は、リモートサーバーで作業する SRE にとって重要です。リモート環境で Codex が生成したコマンドやログをローカルにコピーする際のストレスが解消され、作業効率が向上します。

### すぐに試せる Tips

1. **`/usage` でトークン使用状況を確認**  
   自分のトークン消費傾向を把握し、高コストな操作を特定して最適化しましょう。
   
2. **`/tui` でフルスクリーン UI を試す**  
   長い会話履歴を扱うプロジェクトでは、検索とマウス選択が便利です。
   
3. **F8 で音声会話を有効化**  
   コーディング中に手を止めずに質問できるか試してみましょう。
   
4. **Mermaid 図を Codex に生成させる**  
   「このフローを Mermaid で図示して」と依頼すれば、ターミナル内で直接図が表示されます。

## まとめ

rust-v0.156.0 は、Codex CLI の使い勝手を大きく向上させるマイルストーンリリースです。フルスクリーン TUI、音声会話のデフォルト化、`/usage` 分析ダッシュボード、worktree セッション管理、Mermaid/数式レンダリングなど、ユーザー体験を変える機能が多数追加されました。同時に、ストリーミング中断時の回復、クリップボード転送、サンドボックス分離、MCP 認証といった細かな安定性・セキュリティ改善も充実しており、日常的に Codex を使うエンジニアにとって信頼性が大幅に向上しています。

特に、フルスクリーン UI と音声会話の組み合わせは、ターミナル内での対話型開発を新しい次元に引き上げる可能性を秘めています。また、`/usage` ダッシュボードによるトークン使用量の可視化は、コスト管理とチーム内でのベストプラクティス共有に役立つでしょう。SRE やインフラエンジニアにとっても、daemon 管理機能とサンドボックス強化により、本番環境に近い設定での安全なテストが容易になりました。

100件を超える変更は、Guardian、MCP、Windows サンドボックス、TUI レンダリング、音声、認証など多岐にわたり、Codex CLI が成熟したプロダクトとして進化し続けていることを示しています。今後のリリースでも、これらの基盤の上にさらなる改善が積み重ねられることが期待されます。
