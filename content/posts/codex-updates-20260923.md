# Codex CLI rust-v0.156.0 リリースノート

## はじめに

OpenAI Codex CLI の **rust-v0.156.0** が 2026年9月22日（GitHub リリース日、UTC）に公開されました。リリースノートの New Features には、次回起動時から使えるオプションのフルスクリーン UI（`/tui`）、音声会話のデフォルト有効化、`/usage` 分析ダッシュボード、エージェントコマンドセンターでのステータスフィルタと worktree セッション作成、6つの新テーマと Mermaid 図・数式の表示、`/daemon` と `--no-daemon` の6項目が並びます。

Bug Fixes では、ターン失敗・中断時のストリーミング回答とプランの保持、tmux / SSH でのクリップボード転送、セッション再開時の Plan モード復元、サンドボックス分離の不備の修正などが挙げられています。Changelog セクションには 525 件の PR が列挙されています。

---

## 注目アップデート深掘り

### 1. オプションのフルスクリーン UI（`/tui`）

`/tui` で、**次回起動時** に使うオプションのフルスクリーン UI を選択できるようになりました。フルスクリーン UI には transcript 検索、マウス選択、右クリックコピーが含まれます（#46732, #46734, #46883, #46895）。

`/tui` は Codex のセッション内で使うスラッシュコマンドで、選択した UI は次回の起動から適用されます。

### 2. 音声会話のデフォルト有効化

音声会話がデフォルトで有効になりました。F8 でのトグル、`/voice settings` での声の選択（今後の会話に適用）、Linux と Windows 向けに同梱された音声ランタイムが含まれます（#44921, #46071, #44622, #44714, #44922）。

あわせて、再生の一時停止中や音声データがまとめて届いたときに発話が欠落する問題も修正されています（#46880）。

## 実用的な活用ポイント

- **`/usage` 分析ダッシュボード**: アカウントの使用状況、トークン合計、プラグインとスキルのアクティビティを確認できます（#45764, #45769）。
- **worktree セッションとステータスフィルタ**: エージェントコマンドセンターでタスクをステータスで絞り込み、worktree セッションを作成できます。worktree サポートはデフォルトで有効になりました（#46839, #45276, #44870）。
- **`/daemon` と `--no-daemon`**: ローカルのバックグラウンドサーバーを `/daemon` から更新するか、`--no-daemon` でバイパスできます（#45854, #46088）。
- **サンドボックス分離の修正**: Windows の inbound 接続、Linux / macOS の特権ソケット、macOS の読み取り専用ファイルハンドル経由の書き込みに関する分離の不備が修正されました（#44639, #45984, #46500）。
- **tmux / SSH のクリップボード転送**: tmux と SSH セッションでのクリップボード転送が修正され、ペーストが個別のキー入力として送られる端末でもタブのインデントが保たれます（#45457, #45454）。
- **personality 設定**: 非推奨の `friendly` / `pragmatic` personality 設定は応答スタイルを選択しなくなりました（#45809）。TUI の personality 選択も削除されています（#44935, #44946）。

## まとめ

rust-v0.156.0 は、フルスクリーン UI（`/tui`）、音声会話のデフォルト有効化、`/usage` 分析ダッシュボード、worktree セッション作成、新テーマと Mermaid 図・数式表示、`/daemon` を追加した機能リリースです。バグ修正では、ストリーミング回答とプランの保持、クリップボード転送、Plan モード復元、プロキシ経由のログインと MCP 認証、サンドボックス分離の不備が対象になっています。

非推奨の `friendly` / `pragmatic` personality 設定はもう応答スタイルを選択しないため、これらを設定している場合は見直してください。
