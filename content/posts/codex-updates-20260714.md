# OpenAI Codex CLI rust-v0.144.2 / rust-v0.144.3 リリース解説

## はじめに

2026年7月14日、OpenAI Codex CLI の Rust 版がバージョン rust-v0.144.2 および rust-v0.144.3 として連続リリースされました。rust-v0.144.2 では Guardian の自動レビュー機能に関する重要なバグ修正が実施され、rust-v0.144.3 はバージョン番号のみのリリースとなっています。

特に rust-v0.144.2 では、プロンプティング関連のリグレッションがロールバックされ、Guardian の自動レビューポリシー、リクエストフォーマット、ツール動作が以前の状態に復元されました。これは Codex CLI の安全性と信頼性を維持するための迅速な対応として注目されます。

## 注目アップデート深掘り

### Guardian 自動レビューポリシーの復元（rust-v0.144.2）

rust-v0.144.2 における最も重要な変更は、Guardian の自動レビュー機能に関するリグレッションの修正です。公式リリースノートには「Restored the previous Guardian auto-review policy, request format, and tool behavior after rolling back a prompting regression」と記載されており、プロンプティングの変更が意図しない挙動を引き起こしたため、以前の安定した状態に戻されました。

> **Note:** Guardian は Codex CLI の安全機能の一つで、生成されたコードやコマンドを自動的にレビューし、潜在的なリスクを検出します。

**なぜこの変更が重要なのか**

Guardian は Codex CLI が提案するコード変更やコマンド実行を自動的に評価し、セキュリティリスクや破壊的な操作を事前に検出する重要な安全装置です。この機能のリグレッションは、意図しない危険なコードが承認される、あるいは逆に安全なコードが誤って拒否されるといった問題を引き起こす可能性があります。特に本番環境に影響を与えるインフラストラクチャコードやデプロイメントスクリプトを扱う際、Guardian の正確な判定は極めて重要です。

今回のロールバック（PR #32672）により、以前の安定したポリシー、リクエストフォーマット、ツール動作が復元され、ユーザーは信頼性の高い自動レビュー機能を再び利用できるようになりました。これは開発者体験とセキュリティの両立において、迅速な問題対応の好例と言えるでしょう。

**実用上の影響**

このバグ修正により、Guardian の判定精度が以前のレベルに戻ったため、Codex CLI を使用した対話的なコード生成やコマンド実行がより安全になります。特に `approval-mode` を使用している環境では、Guardian の正確な評価に基づいた承認フローが正常に機能するため、チーム開発における安全性が向上します。

### バージョンのみリリース（rust-v0.144.3）

rust-v0.144.3 は「Published a version-only release with no merged pull request changes since rust-v0.144.2」と記載されている通り、コード変更を含まないバージョン番号のみのリリースです。

このようなリリースは、リリース管理上の理由（タグ付けの整合性、ビルドパイプラインの調整、バージョニングスキームの統一など）で行われることがあります。ユーザーにとっては、rust-v0.144.2 と機能的に同一であるため、すでに rust-v0.144.2 を使用している場合は緊急のアップデートは不要です。ただし、最新のバージョン番号を使用することで、将来のアップデートパスが明確になるため、適切なタイミングでの更新を推奨します。

## 実用的な活用ポイント

### Guardian 修正後の安全な運用

rust-v0.144.2 で Guardian の動作が安定したことで、Codex CLI をインフラストラクチャコードの生成やレビューに使用する際の信頼性が向上しました。特に SRE やインフラエンジニアがインフラストラクチャ as コード（IaC）のテンプレート生成や、運用スクリプトの作成を行う際、Guardian の正確な評価により、誤って危険な操作を承認してしまうリスクが低減されます。

### アップデート推奨

現在 rust-v0.144.1 以前のバージョンを使用している場合、Guardian のリグレッション問題を回避するため、rust-v0.144.2 または rust-v0.144.3 へのアップデートを強く推奨します。特に本番環境やチーム開発で Codex CLI を使用している場合、安全性の観点から早期の更新が望ましいでしょう。

### バージョン確認方法

現在使用中の Codex CLI のバージョンは以下のコマンドで確認できます：

```bash
$ codex --version
```

最新バージョンへの更新は、インストール方法に応じた手順で実施してください。更新後は、特に Guardian を使用する機能（approval mode など）が正常に動作することを確認すると良いでしょう。

## まとめ

今回の rust-v0.144.2 および rust-v0.144.3 リリースは、機能追加よりも安定性と信頼性の維持に焦点を当てたアップデートとなりました。特に rust-v0.144.2 における Guardian の修正は、Codex CLI の安全性を保つための重要な対応であり、迅速なロールバックによりユーザーへの影響を最小限に抑えた点が評価できます。

rust-v0.144.3 はコード変更を含まないものの、リリース管理の一環として公開されており、ユーザーは最新のバージョン番号を使用することで、今後のアップデートパスを明確に保つことができます。

Codex CLI を業務で活用するエンジニアにとって、Guardian のような安全機能の正確な動作は極めて重要です。今回のような迅速なバグ修正対応は、プロダクトの成熟度と開発チームの品質へのコミットメントを示すものと言えるでしょう。現在古いバージョンを使用している場合は、安全性向上のため早期のアップデートを検討することをお勧めします。
